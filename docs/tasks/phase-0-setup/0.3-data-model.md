# Task 0.3: Create Application Data Model

## Objective
Create the central data configuration file for all personalized content.

## Requirements
1. Create `src/data/birthdayData.js`.
2. Export `birthdayData` object containing placeholders for: `name`, `quotes`, `letter`, `albums`, `songs`.
3. Folder names inside `albums` MUST be strictly `"MoFu"` and `"She/Her"`.

## Constraints
- Do NOT hardcode personal text or album definitions inside JSX components.

## Acceptance Criteria
- [ ] `src/data/birthdayData.js` exists and exports the structured configuration object.
- [ ] Folder names `"MoFu"` and `"She/Her"` are explicitly defined in the data structure.
