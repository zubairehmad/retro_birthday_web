# Task 0.2: Establish Project Structure

## Objective
Set up the core directory layout for source files and public assets.

## Requirements
1. Create source directories: `src/components`, `src/screens`, `src/data`, `src/assets`.
2. Create public directories: `public/assets/images`, `public/assets/videos`, `public/assets/audio/effects`, `public/assets/audio/songs`, `public/assets/textures`, `public/assets/decorations`.

## Constraints
- Do NOT create unnecessary abstraction folders.

## Acceptance Criteria
- [ ] All directories are present and correctly placed according to `project-specifications.md`.
