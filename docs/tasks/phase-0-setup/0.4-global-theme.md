# Task 0.4: Create Global Theme & CSS Variables

## Objective
Establish the foundational retro/vintage visual tokens and base styles.

## Requirements
1. Define CSS custom properties in `src/App.css` or `src/index.css`:
   - `--cream`, `--paper`, `--red`, `--pink`, `--brown`, `--olive`.
2. Set up base font rules and global reset margins/padding.
3. Apply warm background styling to the base layout wrapper.

## Constraints
- Keep styling foundational; do NOT style specific screen components yet.

## Acceptance Criteria
- [ ] CSS variables are accessible globally.
- [ ] Base root layout reflects the retro cream background color.
