# Task 0.1: Create React Application

## Objective
Initialize the base React application setup.

## Requirements
1. Create a clean React application (using Vite or standard setup).
2. Configure basic development and build scripts in `package.json`.
3. Clean out default starter template code, demo logos, and unnecessary default CSS.

## Constraints
- Do NOT implement any birthday UI components, screens, or styling yet.

## Acceptance Criteria
- [ ] Application starts locally without runtime errors.
- [ ] Production build (`npm run build`) compiles without errors.
