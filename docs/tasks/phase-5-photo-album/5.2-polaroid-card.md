# Task 5.2: Create Polaroid Frame Component

## Objective
Build a styled polaroid card component to display individual photos with handwritten captions[cite: 1, 2].

## Requirements
1. Create `src/components/PolaroidCard.jsx` accepting `imageSrc`, `caption`, and `onClick` props[cite: 1, 2].
2. Style with white/off-white thick border frame, subtle drop shadow, and slight random tilt/rotation[cite: 1, 2].
3. Display caption underneath image using handwritten style font[cite: 1, 2].
4. Add hover/focus subtle lift effect[cite: 1, 2].

## Constraints
- Keep rotation angles small (e.g., -2 deg to 2 deg) so layout grid stays organized[cite: 1, 2].

## Acceptance Criteria
- [ ] PolaroidCard renders image within authentic retro polaroid frame with caption below[cite: 1, 2].
- [ ] Interactive hover state applies smooth scale/lift effect[cite: 1, 2].
