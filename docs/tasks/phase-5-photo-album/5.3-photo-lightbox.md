# Task 5.3: Implement Photo Lightbox Modal

## Objective
Build full-screen lightbox modal for viewing high-resolution images with photo navigation[cite: 1, 2].

## Requirements
1. Create `src/components/PhotoLightbox.jsx` accepting `activePhoto`, `photos` array, and `onClose` callback[cite: 1, 2].
2. Overlay semi-transparent dark vintage backdrop with close button (`✕`)[cite: 1, 2].
3. Add Next (`>`) and Previous (`<`) navigation controls to cycle through images[cite: 1, 2].
4. Support keyboard navigation (Escape to close, Left/Right arrows to navigate)[cite: 2].

## Constraints
- Prevent background body scrolling when lightbox modal is open[cite: 2, 3].

## Acceptance Criteria
- [ ] Clicking any polaroid opens image in full-screen lightbox modal[cite: 1, 2].
- [ ] Arrow buttons and keyboard keys switch active photo[cite: 1, 2].
- [ ] Close button or Escape key dismisses modal and restores background scroll[cite: 2, 3].
