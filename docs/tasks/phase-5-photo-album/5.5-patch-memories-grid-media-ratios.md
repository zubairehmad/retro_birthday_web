# Patch Task 5.5: Refine Memories Grid and Media Ratios

## Reason for Change

The current Memories cards can become too wide on desktop, while media previews crop or present portrait photos too small. The grid and media containers need explicit, responsive proportions.

## Updated Requirements

1. Keep the Memories grid centered and responsive with CSS Grid.
2. Cap each desktop card to a visually balanced 4:3 width-to-height ratio and a reasonable maximum width.
3. Allow mobile cards to use the available width without awkward large-screen stretching.
4. Use a capped 3:4 media container for portrait-efficient previews.
5. Center image and video content with `object-fit: contain`, preserving the complete source media.
6. Do not add a colored background behind media; unused container space must blend with the existing card/page styling.
7. Preserve retro styling, category tabs, lightbox behavior, and responsive navigation.

## Boundaries / Impact

- Affected files: `src/App.css`, `src/memories-layout.css`, and `src/main.jsx` for final stylesheet ordering.
- Do not modify media data, screen state, or unrelated components.

## Acceptance Criteria

- Desktop cards are capped, centered, and maintain a 4:3 ratio.
- Desktop columns adapt naturally to available width.
- Mobile cards remain readable and may widen within the viewport.
- Preview containers are capped near 3:4 and show portrait and landscape media fully.
- No added colored media placeholder/background is visible.
- HBD music pauses on video `play` and resumes on video `pause`, `ended`, or stop/close without changing when the viewer opens.
- `npm run build` passes.
