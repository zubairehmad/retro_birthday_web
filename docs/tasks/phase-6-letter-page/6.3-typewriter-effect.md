# Task 6.3: Implement Typewriter Unveil Effect

## Objective
Add progressive typewriter text reveal animation when opening the letter[cite: 1, 2].

## Requirements
1. Create state to track visible character count of the letter body[cite: 1, 2].
2. Use `setInterval` or `requestAnimationFrame` to reveal characters progressively[cite: 1, 2].
3. Include "Skip Animation" action button allowing user to instantly reveal complete letter text[cite: 1, 2].
4. Play soft subtle key click audio effect during typing if available[cite: 2].

## Constraints
- Automatically clear typewriter timers on component unmount or when skip is clicked[cite: 2, 3].

## Acceptance Criteria
- [ ] Opening letter gradually types out letter text[cite: 1, 2].
- [ ] Clicking "Skip" immediately displays full text and stops animation/audio[cite: 1, 2].
- [ ] Unmounting component cleans up active animation frames/timers[cite: 2, 3].
