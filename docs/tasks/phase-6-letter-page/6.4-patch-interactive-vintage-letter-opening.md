# Patch Task 6.4: Implement Interactive Vintage Letter Opening

## Reason for Change

The Letter page currently presents the message immediately as a typing card. It needs to begin as a tactile vintage envelope and reveal the existing birthday letter through a deliberate, accessible opening sequence.

## Updated Requirements

1. Start with a centered, keyboard-accessible envelope button styled as vintage stationery.
2. Use a small `closed` / `opening` / `opened` state flow for the lift, flap, letter emergence, and content reveal.
3. Keep the envelope partially visible behind the opened letter.
4. Render the existing `birthdayData.letter` content without inventing personal content.
5. Keep the experience responsive and prevent horizontal scrolling.
6. Respect `prefers-reduced-motion` and keep the existing BackButton/navigation behavior.

## Boundaries / Impact

- Affected files: `src/screens/LetterPage.jsx` and Letter page rules in `src/App.css`.
- Reuse existing data, button, audio, and navigation infrastructure.
- Do not add dependencies or redesign unrelated screens.

## Acceptance Criteria

- The closed envelope is clearly interactive and has visible keyboard focus.
- Opening visibly lifts the envelope, opens its flap, and slides the paper upward.
- Letter content appears after the paper emerges, with the envelope still visible behind it.
- The letter remains readable on desktop, tablet, and mobile.
- Reduced motion preserves the state change without long animation delays.
- Existing navigation remains available and no personal text is hardcoded into the component.
