- Affected files: `src/components/RetroButton.jsx` and `src/screens/InitialScreen.jsx`.
- Do not change dedicated Initial Screen sounds or other screens' click feedback.

## Acceptance Criteria

- NO plays only the dedicated NO sound.
- Navigation buttons outside Initial Screen still play the shared click sound.
- `npm run build` passes.
