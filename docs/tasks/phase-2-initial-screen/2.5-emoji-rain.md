# Task 2.5: Create EmojiRain Component

## Objective
Build a reusable programmatic emoji particle rain component[cite: 1, 2].

## Requirements
1. Create `src/components/EmojiRain.jsx` accepting `emojis` (array), `count`, and `duration` props[cite: 2].
2. Generate random particle metadata (X position, scale, rotation, drop delay, fall speed)[cite: 1, 2].
3. Render falling CSS-animated emoji elements and cleanly unmount/cleanup after duration completes[cite: 2].

## Constraints
- Keep particle count bounded to prevent DOM accumulation or frame drops[cite: 2, 3].

## Acceptance Criteria
- [ ] `EmojiRain` renders falling, randomized emojis across screen viewport[cite: 1, 2].
- [ ] All particle elements automatically clean up from DOM after animation completes[cite: 2, 3].
