# Task 2.4: Create Audio Effect Infrastructure

## Objective
Build a simple, robust utility for playing short UI sound effects safely[cite: 2].

## Requirements
1. Create `src/utils/audio.js` (or `src/audio/soundEffects.js`)[cite: 2, 3].
2. Export a helper function `playSound(src)` to instantiate and play audio files[cite: 2].
3. Wrap playback in try/catch handling to gracefully recover if browser blocks audio or asset is missing[cite: 2].

## Constraints
- Do NOT add continuous background music logic here; this is exclusively for short sound effects[cite: 2].

## Acceptance Criteria
- [ ] `playSound()` utility cleanly triggers audio files[cite: 2].
- [ ] Missing audio files or blocked playback do not throw unhandled crashes[cite: 2].
