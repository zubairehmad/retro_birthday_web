# Task 2.7: Implement Desktop NO Button Evasion

## Objective
Create mouse pointer avoidance movement for the NO button on desktop devices[cite: 1, 2].

## Requirements
1. Wrap NO button in a dedicated bounded interaction container[cite: 1, 2].
2. Track mouse coordinates relative to the NO button position[cite: 2].
3. When pointer enters proximity threshold, recalculate button `(x, y)` position to jump away within container boundaries[cite: 1, 2].
4. Apply smooth transition CSS (`transition: transform 180ms ease`)[cite: 1, 2].

## Constraints
- NO button MUST stay strictly inside container bounds and NEVER cause page scrollbars[cite: 1, 2].

## Acceptance Criteria
- [ ] Mouse cursor approaching NO button triggers button to dodge away[cite: 1, 2].
- [ ] Button position never overflows viewport or breaks page layout[cite: 1, 2].
