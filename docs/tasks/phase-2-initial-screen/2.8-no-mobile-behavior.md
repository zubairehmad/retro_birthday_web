# Task 2.8: Implement Mobile NO Button Interaction

## Objective
Add touch-friendly playful reaction when NO button is tapped on mobile devices[cite: 1, 2].

## Requirements
1. Detect touch interaction / mobile viewport mode[cite: 2].
2. Define `sadEmojis` array (`😭`, `😢`, `💔`, `😡`, `🥺`, `😤`, `☹️`, `💢`) in config[cite: 1, 2].
3. On tap: play `nooo.mp3` sound effect and trigger sad `EmojiRain` without leaving the Initial Screen[cite: 1, 2].

## Constraints
- Do NOT run cursor-evasion pointer tracking logic on touch devices[cite: 1, 2].

## Acceptance Criteria
- [ ] Tapping NO button on touch screens triggers `nooo.mp3` and sad emoji rain[cite: 1, 2].
- [ ] User remains on Initial Screen and can tap YESS! afterwards[cite: 1, 2].
