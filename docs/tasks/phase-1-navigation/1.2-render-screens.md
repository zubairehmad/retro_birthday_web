# Task 1.2: Render Screen Placeholders

## Objective
Create placeholder screen components and render them conditionally based on screen state.

## Requirements
1. Create minimal functional components in `src/screens/`:
   - `InitialScreen.jsx`
   - `HbdScreen.jsx`
   - `MainScreen.jsx`
   - `PhotoAlbum.jsx`
   - `LetterPage.jsx`
   - `MusicPage.jsx`
2. Conditionally render the active component in `App.jsx` based on `screen` state.

## Constraints
- Keep screen components minimal (e.g., return a single `div` with the screen name text).

## Acceptance Criteria
- [ ] Manually changing default `screen` state in code renders the matching placeholder component.
