# Task 1.3: Implement Navigation Callbacks

## Objective
Connect navigation flows across all screen placeholders.

## Requirements
1. Pass navigation handler functions (`onNext`, `onBack`, `onOpenAlbum`, etc.) from `App.jsx` to screens.
2. Connect screen callbacks:
   - Initial -> HBD
   - HBD -> Main
   - Main -> Album / Letter / Music
   - Album / Letter / Music -> Main

## Constraints
- Do NOT add screen transition animations yet.

## Acceptance Criteria
- [ ] Clicking temporary trigger elements successfully navigates forward and back through the entire user flow.
