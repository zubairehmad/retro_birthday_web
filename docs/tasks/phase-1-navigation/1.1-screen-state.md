# Task 1.1: Create Screen State Management

## Objective
Implement state management for application page routing.

## Requirements
1. In `src/App.jsx`, add top-level state `screen` (default `"initial"`).
2. Supported screen state string values: `"initial"`, `"hbd"`, `"main"`, `"album"`, `"letter"`, `"music"`.

## Constraints
- Do NOT add external routing libraries like `react-router` unless specifically required. State-based navigation is sufficient.

## Acceptance Criteria
- [ ] Application state correctly holds and updates the active screen value.
