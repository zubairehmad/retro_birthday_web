# Task 1.4: Create Shared Button Components

## Objective
Build reusable, base button components for application-wide use.

## Requirements
1. Create `src/components/RetroButton.jsx` for primary actions.
2. Create `src/components/BackButton.jsx` for navigation back actions.
3. Apply initial physical/retro styling rules (border, slight shadow, cursor pointer).

## Constraints
- Keep animations simple (standard CSS hover/active states only).

## Acceptance Criteria
- [ ] `RetroButton` and `BackButton` are functional, styled, and accept `onClick` and `children` props.
