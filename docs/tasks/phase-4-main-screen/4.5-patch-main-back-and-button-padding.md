# Patch Task 4.5: Add Main Back Navigation and Consistent Button Padding

## Reason for Change

The Main Screen needs a clear route back to the HBD Screen, and action buttons currently have inconsistent spacing. Improve navigation clarity and make Continue/NEXT/back controls comfortable to use.

## Updated Requirements

1. Add a Main Screen back button that navigates to the HBD Screen without a full-page reload.
2. Wire the back action through the existing application screen state.
3. Give the HBD Continue/NEXT button more padding.
4. Apply consistent readable padding to shared Continue, NEXT, Back, and related action buttons throughout the application.
5. Preserve existing navigation destinations, button styling, audio behavior, responsive layouts, and card interactions.

## Boundaries / Impact

- Affected files: `src/App.jsx`, `src/screens/MainScreen.jsx`, `src/components/RetroButton.jsx`, `src/components/BackButton.jsx`, and related rules in `src/App.css`.
- Do not alter HBD song ownership or screen content.
- Do not change card navigation behavior or introduce full-page navigation.

## Acceptance Criteria

- Main Screen visibly provides a Back button that returns to HBD Screen.
- HBD Continue/NEXT has increased padding without colliding with its border.
- Shared action buttons have consistent padding across Initial, HBD, Main, Album, Letter, and Music screens.
- Existing button hover/active behavior and responsive layout remain intact.
