# Task 4.4: Add Decorative Vintage Elements

## Objective
Enhance Main Screen atmosphere with vintage stickers, tape accents, and ambient decorations[cite: 1, 2].

## Requirements
1. Position decorative tape graphics on top corners of navigation cards[cite: 1, 2].
2. Scatter subtle vintage stickers/decorations (stamps, stars, flower decals) around background margins[cite: 1, 2].
3. Ensure decorations use non-interactive styling (`pointer-events: none`) so they don't block clicks[cite: 2].

## Constraints
- Keep background elements lightweight so mobile viewports do not overflow horizontally[cite: 1, 2].

## Acceptance Criteria
- [ ] Visual polish matches vintage scrapbook specifications without obscuring navigation cards[cite: 1, 2].
- [ ] No horizontal scrollbars or touch blockage introduced[cite: 1, 2].
