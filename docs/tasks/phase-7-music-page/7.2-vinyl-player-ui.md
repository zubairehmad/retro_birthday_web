# Task 7.2: Build Vinyl/Cassette Visual Component

## Objective
Create vintage animated music visualizer element (spinning vinyl record or cassette tape)[cite: 1, 2].

## Requirements
1. Create `src/components/VinylPlayer.jsx` rendering vinyl record or cassette graphics[cite: 1, 2].
2. Apply continuous CSS rotation animation when a track is currently playing[cite: 1, 2].
3. Display current active track metadata (title, artist, album art) in center player display[cite: 1, 2].
4. Pause rotation animation smoothly when audio playback is paused[cite: 1, 2].

## Constraints
- Keep rotation CSS efficient (`will-change: transform`) to maintain 60 FPS performance on mobile[cite: 2, 3].

## Acceptance Criteria
- [ ] Vinyl/Cassette graphic spins when audio is playing and pauses when stopped[cite: 1, 2].
- [ ] Active track info updates accurately on track selection[cite: 1, 2].
