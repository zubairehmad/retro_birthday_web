# Task 7.3: Implement Audio Player Controls & Logic

## Objective
Integrate custom HTML5 audio controls for playlist tracks[cite: 1, 2].

## Requirements
1. Implement audio playback state (`isPlaying`, `currentTrackIndex`, `progress`, `duration`)[cite: 1, 2].
2. Add control actions: Play/Pause, Next Track, Previous Track[cite: 1, 2].
3. Add interactive progress bar showing elapsed time and allowing scrubbing[cite: 1, 2].
4. Auto-play next track in list when current track ends[cite: 1, 2].

## Constraints
- Ensure proper cleanup of standard HTML5 `Audio` instance event listeners on unmount[cite: 2, 3].

## Acceptance Criteria
- [ ] Play, pause, next, previous, and progress scrub controls function accurately[cite: 1, 2].
- [ ] Tracks auto-advance seamlessly when finished[cite: 1, 2].
- [ ] Navigating away stops audio playback cleanly without background memory leaks[cite: 2, 3].
