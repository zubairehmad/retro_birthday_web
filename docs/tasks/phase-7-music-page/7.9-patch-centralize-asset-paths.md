# Patch Task 7.9: Centralize Asset Paths

## Reason for Change

Asset filenames are currently repeated in components and application logic, making updates error-prone. A shared asset map should be the single source for image, video, song, and sound-effect paths.

## Updated Requirements

1. Define named asset path constants in a shared data/config module.
2. Reference the asset map from components, application audio setup, and birthday data.
3. Remove hardcoded `/assets/...` paths from React components and utility call sites.
4. Preserve all existing media, sound, and playback behavior.

## Boundaries / Impact

- Affected files: `src/data/assets.js`, `src/data/birthdayData.js`, sound-playing components, `src/App.jsx`, and `src/utils/audio.js` call sites.
- Do not change asset filenames or unrelated UI behavior.

## Acceptance Criteria

- All application asset paths are declared in one shared map.
- Components contain no hardcoded asset paths.
- Images, videos, songs, HBD audio, and click/initial sound effects continue to resolve.
- `npm run build` passes.
