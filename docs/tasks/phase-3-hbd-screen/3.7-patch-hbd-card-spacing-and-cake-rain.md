# Patch Task 3.7: Rebuild HBD Card Spacing and Cake Celebration

## Reason for Change

The current HBD screen still feels poorly composed despite the previous visual polish. It needs a properly spaced central card, tasteful surrounding decorations and birthday emojis, a clear congratulatory message, and an obvious cake button whose interaction starts the emoji-rain celebration.

## Updated Requirements

1. Rework the HBD card composition with comfortable padding, deliberate vertical rhythm, and clear separation between the heading, congratulations, cake button, quote, and Continue action.
2. Make the screen's primary message explicitly congratulate the user and give it the strongest visual hierarchy.
3. Curate a small, cohesive set of birthday emojis and decorative accents around the card; keep them cute, balanced, and non-obstructive.
4. Make the birthday cake visually prominent and clearly identifiable as an interactive button with accessible focus and pressed/hover feedback.
5. On every cake click/tap, trigger a visible emoji-rain burst using the existing bounded `EmojiRain` behavior; the interaction must remain repeatable and non-blocking.
6. Preserve quote rotation, cake sound behavior, Continue navigation, root-level celebration behavior, responsive layout, and mobile usability.
7. Prevent horizontal overflow and maintain readable contrast at desktop and narrow mobile widths.

## Boundaries / Impact

- Affected files: `src/screens/HbdScreen.jsx`, related HBD styles in `src/App.css`, and only the existing celebration data/config if needed for curated emojis.
- Do not alter application navigation state, the shared `EmojiRain` lifecycle, audio utility behavior, unrelated screens, or user-authored sound-effect fixes.
- Do not add external UI, animation, or state-management dependencies.
- Do not modify completed HBD task files; this is a follow-up patch to the completed 3.6 work.

## Acceptance Criteria

- The HBD screen presents a centered, properly padded card with consistent spacing and no cramped overlaps.
- A clear congratulatory birthday message is the focal content.
- Surrounding decorations and birthday emojis look intentional, cute, and balanced without blocking content or controls.
- The cake is visibly a button, has accessible focus feedback, and remains easy to activate.
- Activating the cake starts a visible emoji-rain burst every time without locking the screen or breaking navigation.
- Quote rotation, cake sound, Continue navigation, responsive behavior, and no-overflow constraints continue to work.
