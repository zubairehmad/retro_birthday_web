# Task 3.3: Implement Dynamic Quote Rotator Component

## Objective
Build a dynamic text rotator component to cycle through personalized quotes[cite: 1, 2].

## Requirements
1. Create `src/components/QuoteRotator.jsx` accepting `quotes` array prop from `birthdayData.js`[cite: 1, 2].
2. Implement timer state (e.g., 3-5 second interval) to cycle through quotes automatically[cite: 1, 2].
3. Apply smooth fade transition effects (opacity/transform) between quote changes[cite: 1, 2].

## Constraints
- Clean up active intervals on component unmount to avoid memory leaks[cite: 2, 3].

## Acceptance Criteria
- [ ] Quotes automatically cycle through elements defined in `birthdayData.js`[cite: 1, 2].
- [ ] Fade transitions render smoothly without layout jumps[cite: 1, 2].
