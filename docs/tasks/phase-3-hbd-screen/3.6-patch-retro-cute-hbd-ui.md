# Patch Task 3.6: Polish HBD Screen with Retro-Cute UI

## Reason for Change

The HBD screen works functionally but needs a stronger visual treatment. It should feel like a polished retro birthday card or scrapbook reveal: cute, warm, celebratory, and visually cohesive with the rest of the website.

## Updated Requirements

1. Refine the HBD screen layout and styling to establish a clear birthday greeting focal point and stronger visual hierarchy.
2. Apply cohesive retro-cute visual language using warm paper tones, pastel accents, rounded surfaces, playful display typography, and soft layered shadows.
3. Add or refine restrained decorative details such as stars, hearts, sparkles, ribbons, stickers, or confetti without making the screen visually noisy.
4. Improve quote-card presentation with readable scrapbook-like placement, varied rotations, and consistent spacing.
5. Keep the interactive cake or birthday focal element visually prominent and clearly actionable.
6. Preserve quote rotation, cake click/tap feedback, confetti or emoji effects, sound behavior, celebration lifecycle, and Continue navigation.
7. Maintain responsive composition, accessible contrast, readable text, and usable controls on desktop and mobile.

## Boundaries / Impact

- Affected files: `src/screens/HbdScreen.jsx`, related HBD styles in `src/App.css`, and only supporting shared styling if required.
- Do not alter navigation state, quote data, audio utility behavior, emoji-rain logic, or unrelated screens.
- Do not add external UI, animation, or state-management dependencies.
- Preserve any user-authored sound-effect fixes already present in the working tree.

## Acceptance Criteria

- HBD screen visibly reads as a polished retro-cute birthday-card/scrapbook reveal.
- Birthday heading, supporting message, quote content, cake/focal element, and Continue action have clear hierarchy.
- Decorative details enhance the design without harming readability or interaction.
- Quote rotations and cake/confetti interactions continue to work as before.
- Layout and typography remain balanced and usable across desktop and mobile viewports.
- No horizontal overflow, broken controls, or regressions in the existing HBD-to-main navigation flow.
