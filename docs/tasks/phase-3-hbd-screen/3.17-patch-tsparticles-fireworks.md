# Patch Task 3.17: Upgrade HBD Fireworks with tsParticles

## Reason for Change

The custom firework animation is not visually realistic enough. Replace the custom DOM/CSS firework implementation with the tsParticles React integration and fireworks preset.

## Updated Requirements

1. Add `@tsparticles/react` and the v4-compatible `@tsparticles/preset-fireworks` dependency.
2. Replace the custom firework particle markup, trajectory state, and firework CSS with a tsParticles fireworks preset.
3. Keep the cake button as the trigger and preserve repeatable bursts without breaking HBD navigation or background music.
4. Use the preset's supported fireworks sound behavior; remove the old manual launch/pop sound scheduling.
5. Use high-contrast particle colors so rising trails remain visible over the HBD background.
6. Limit each cake-triggered burst to 5–10 fireworks and prevent indefinite emitter shooting.
7. Keep the effect layered, non-interactive, responsive, and bounded to the HBD screen.
8. Preserve active bursts when later cake taps occur; new taps must add animations rather than remounting or clearing existing ones.
9. Give each burst a stable unique key and avoid duplicate React children.
10. Keep rendering lightweight with a low emitter rate and remove each burst canvas after its particles naturally finish.
11. Do not load project firework audio assets; use only the preset's own sound behavior.
12. Initialize the particle provider before the first cake click so preset audio is ready on the first interaction.
13. Let each canvas finish naturally without removing it on a fixed duration timeout.

## Boundaries / Impact

- Affected files: `package.json`, `src/components/Fireworks.jsx`, `src/components/fireworks.css`, and `docs/progress.md`.
- Do not alter HBD song ownership, cake button semantics, navigation, or unrelated emoji-rain behavior.
- Do not add another animation library or change the existing sound-effect helper used elsewhere.

## Acceptance Criteria

- Cake clicks render a realistic tsParticles fireworks effect.
- Repeated cake clicks trigger additional fireworks without cancelling the current effect.
- The preset is initialized before the first click, and subsequent bursts do not interrupt HBD background music.
- The visual layer does not capture pointer input or obscure HBD controls.
- No custom firework DOM trajectory, burst CSS, or delayed manual firework sound timers remain.
- The project dependencies and imports are buildable with the existing Vite React setup.
