# Task 9.4: Main Screen Full UI Overhaul

## Objective
Redesign the Main Screen hub to present a modern, visually appealing vintage menu with distinct rounded cards for Photos, Letter, and Music options.

## Requirements
1. Replace current raw layout with a structured grid/flex layout of rounded navigation cards (e.g., Photos 📷, Letter 💌, Music 📼).
2. Give each navigation card distinct visual hierarchy: custom retro icons, bold handwritten titles, subtitle descriptions, and rounded borders.
3. Implement rich micro-interactions on hover and active states (slight lift, rotation, scale, and subtle shadow expansion).
4. Add decorative stickers/doodles around the card container to maintain the cute scrapbook theme.

## Constraints
- Maintain existing state-based navigation callbacks (`setScreen("album")`, `setScreen("letter")`, `setScreen("music")`).

## Acceptance Criteria
- [ ] Main Screen exhibits a polished, modern-retro UI with distinct rounded card elements.
- [ ] Cards display clear hover/active animations.
- [ ] Mobile view stacks cards cleanly without breaking layouts.
