# Task 9.1: Global Theme & Rounded Card Styling

## Objective
Update CSS design tokens to establish a cohesive modern-vintage aesthetic using rounded border rectangles and refined card shadows.

## Requirements
1. Update CSS variables in `src/App.css` or `src/index.css` for standardized border radii (e.g., `--radius-card: 16px`, `--radius-btn: 12px`, `--radius-pill: 9999px`).
2. Add global utility classes for rounded retro container cards (`.retro-card-rounded`) with subtle multi-layered drop-shadows and vintage borders.
3. Apply rounded button styles globally to ensure buttons across all screens share uniform padding, rounded corners, and tactile hover/active states.

## Constraints
- Preserve warm cream/beige background palettes and retro font pairings from `project-specifications.md`.

## Acceptance Criteria
- [ ] Global buttons and cards utilize smooth rounded borders.
- [ ] Visual elements maintain consistent padding, borders, and shadows across all screens.
